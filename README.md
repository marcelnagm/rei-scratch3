# rei-scratch3

Coleção de projetos feitos em **Scratch 3** (arquivos `.sb3`), com as respostas das atividades em PDF.

## Projetos

| Arquivo | Descrição |
|---|---|
| `20 + 20.sb3` | Atividade de soma (resposta em `resposta 20 + 20.pdf`) |
| `42.sb3`, `67 .sb3` | Atividades com os números 42 e 67 (respostas em `resposta 42 e 67.pdf`) |
| `Gato.sb3` | Projeto base com o gato do Scratch |
| `Gato Voador.sb3`, `Gato Voador h1.sb3`, `Gato Voador h2.sb3` | Variações do projeto "Gato Voador" (resposta em `resposta gato voador.pdf`) |
| `dancante.sb3` | Animação de personagem dançando |
| `☆ Star Catcher ☆.sb3` | Jogo de pegar estrelas |

A pasta `an/` guarda cópias de parte dos projetos.

## Como abrir

1. Acesse [scratch.mit.edu/create](https://scratch.mit.edu/create).
2. Menu **Arquivo → Carregar do seu computador**.
3. Escolha o arquivo `.sb3` desejado.

Também funciona no editor offline do Scratch 3.
